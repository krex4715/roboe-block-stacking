# ④ 파지 판단 — Gripper 관절 상태 기반 판정

> **입력** :  로봇 관절 상태 (Proprioception)
> **출력** :  파지 성립/해제 판정 → Belief 동결, 강체 부착 트리거




## 판정 로직

시뮬레이터 내부 정보 (접촉 센서, 정답 상태) 없이 로봇 관절 상태만 사용:

- **파지 성립** = Gripper 관절 폭이 큐브 한 변(51.5mm) 근처에서 안정 + 손끝이 목표 옆.
  이 시점에 해당 큐브의 Belief 를 동결하고 손에 강체 부착
- **놓음** = Gripper 열림. 부착 해제 후 재검출 재개
- 캘리브레이션 불필요. 판정은 매 물리 스텝 수행 (파지 신호가 스텝 단위로 깜빡여서
  10Hz 샘플링으로는 부착 타이밍을 놓침, 실측)




## 이유

- 실물 로봇에는 시뮬레이터가 없음. 관절 인코더는 항상 있으므로 실물 이식 시
  이 로직이 그대로 감
- 파지/운반 중에는 큐브가 Gripper 에 가려 인식이 불안정한 구간.
  [③](03_decision_control.md)의 "조작 중 동결"과 같이 동작해서 운반 중 목표 튐을 차단




**코드**: `perception/cortex_bridge.py` 의 `tick()` (매 물리 스텝 호출)
