# ④ 파지 판단 — "잡았는가"를 시뮬레이터에 묻지 않기

> **입력** :  로봇 자신의 관절 상태 (Proprioception)
> **출력** :  파지 성립/해제 판정 → belief 동결·강체 부착 트리거




## 판정 로직

시뮬레이터 내부 정보(접촉 센서, 정답 상태)를 쓰지 않고, 로봇이 스스로 아는 것만 사용:

- **파지 성립** = Gripper 관절 폭이 큐브 한 변(51.5mm) 근처에서 안정 + 손끝이 목표 옆
  → 그 순간 해당 큐브의 belief **동결** + 손에 **강체 부착**
- **놓음** = Gripper 열림 → 부착 해제, 재검출 재개
- 별도 캘리브레이션 불필요. **매 물리 스텝** 판정 — 파지 신호가 스텝 단위로 깜빡여서
  10Hz 로 샘플링하면 엇박이 나 부착이 안 걸림 (실측)




## 왜 이렇게?

- 실물 로봇에는 "시뮬레이터에게 묻기"가 없음. 관절 인코더는 항상 있음 →
  실물 이식 시 이 로직이 그대로 감
- 파지·운반 중에는 큐브가 Gripper 에 가려 인식이 흔들리는 구간 —
  [③](03_decision_control.md)의 "조작 중 동결"과 맞물려 운반 중 목표 튐을 차단




**코드**: `perception/cortex_bridge.py` 의 `tick()` (매 물리 스텝 호출)
