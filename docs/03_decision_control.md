# ③ 판단·제어 — 인식 결과만 보고 움직이기 (belief 분리)

**입력** [②](02_grasp_point.md)의 (클래스, 3D 위치, yaw) → **출력** 로봇 행동
(어느 큐브를 언제 집어 어디에 놓을지).

## belief 분리 — 로봇은 고스트만 본다

베이스인 Cortex(Isaac Sim 의 로봇 의사결정 프레임워크)는 "로봇이 믿는 세계(belief)"와
"실제 물리 세계"를 구분함. 이 구조를 그대로 이용:

- 로봇에는 **렌더링 꺼진 고스트 큐브**만 등록 — 인식 결과가 고스트를 움직이고,
  로봇은 고스트를 보고 계획하며, 물리적으로는 진짜 큐브를 집음
- 물리 큐브를 그대로 등록하면 인식을 꺼도 완벽히 동작해버림 → **인식이 기여하는지
  증명 불가**. 고스트 구조라서 "belief 를 36cm 오염시켜도 교정해 완주"가 증명이 됨
- 인식→belief 통로는 Cortex 가 인식 연동용으로 설계해 둔
  `CortexObject.set_measured_pose()` 하나. 의사결정 로직은 쌓기 순서 설정 외 무수정

## Cortex Bridge — 발행 전 5중 필터

원칙 하나: **"조작 중에는 belief 를 건드리지 않는다."**

| 안전장치 | 막는 문제 |
|---|---|
| 신뢰도 게이트 + 클래스별 1개 선택 | 유령·중복 검출 |
| EMA 필터 + 데드밴드 8mm | 프레임 간 흔들림으로 목표가 계속 미세 이동 |
| 조작 중 동결 + 파지 시 강체 부착 | 잡으러 가는 중·운반 중에 목표가 튐 |
| 작업공간 게이트 | 가림·배경 깊이가 만드는 불가능한 3D 값 |
| 탑 보호 | 오검출 하나가 완성 탑을 무너뜨림 |

E2E 매트릭스(README 결과 표)에서 실패 13회가 전부 "정체 → 타임아웃"이고 **탑 붕괴
0회**인 이유가 이 필터 — Qwen 은 회당 최대 45회 기각되면서도 10/10 완주.

## 행동 계층에서 해결한 것 (제어기 무수정)

- **carry-high 운반**: 낮게 운반하면 장애물 회피력과 목표 인력이 상쇄돼 탑 앞 정체
  → 운반 경로 상향으로 해소
- **최소 회전 파지**: 큐브는 90° 대칭 = 등가 파지 자세 4개 → 손목 회전 최소인 것 선택
  → 손목이 관절 한계까지 감기는 교착 제거
- **정체 감시자**: EE 가 4초간 5mm 미만 이동이면 장애물 임시 해제(2s) + 자세 섭동으로 탈출
