# ③ 판단·제어 — 인식 결과로 Belief 갱신, Belief 기반 행동 결정

> **입력** :  [②](02_grasp_point.md)의 (클래스, Position, yaw)
> **출력** :  로봇 행동 (어느 큐브를 집어 어디에 놓을지) → Franka 관절 명령




## 구조 — Belief World / Physical World 분리

베이스 프레임워크인 Cortex 는 로봇이 믿는 세계(Belief World)와 실제 물리 세계
(Physical World)를 구분해서 관리함. 이 과제에서는:

| | 내용 |
|---|---|
| Physical World | 실제 큐브. 카메라에 찍히고 손에 잡히는 대상 |
| Belief World | 로봇 의사결정이 보는 세계. 렌더링을 끈 Ghost 큐브 4개 |

로봇에는 Ghost 만 등록되어 있음. 인식 결과가 Ghost 를 실제 큐브 위치로 옮기고,
로봇은 Ghost 를 보고 계획해서 실제 큐브를 집는 구조.

Physical 큐브를 그대로 등록하면 (스톡 예제 방식) 인식을 꺼도 동작하기 때문에,
인식이 실제로 기여하는지 확인할 방법이 없음. Ghost 로 분리했기 때문에 "Belief 를
평균 36cm 틀리게 시작시켜도 인식이 교정해서 완주" 같은 실험(README 의 랜덤 배치,
Advanced Ver.)이 가능해짐.




## 데이터 흐름

1. ② 의 추정값이 Cortex Bridge 로 들어옴 (아래 5중 필터)
2. 필터를 통과한 것만 `CortexObject.set_measured_pose()` 로 발행.
   Cortex 가 인식 연동용으로 제공하는 API 이고, 프레임워크가 measured pose 를
   Belief 에 동기화함 (= Ghost 이동)
3. Decider Network 가 Belief 를 보고 다음 행동을 선택
4. MotionCommander(RMPFlow) 가 목표를 관절 움직임으로 변환. 제어기는 무수정

관측이 1초 이상 끊기면 (가림 등) measured pose 는 자동 만료되고 Belief 는 마지막
값을 유지함. 로봇이 매 프레임 인식에 의존하지 않고 가장 최근의 유효한 관측으로
움직이는 구조라서, 인식이 느려도 (GDINO 2~3Hz, Qwen 0.2Hz) 완주가 가능함.




## Cortex Bridge — Belief 갱신 전 5중 필터

인식에는 노이즈가 있고 Belief 는 곧 로봇의 목표라서, 필터 없이 갱신하면 사고가 남.
기본 원칙은 "조작 중에는 Belief 를 건드리지 않는다". 각 필터는 실제 겪었던 문제의
처방임:

| 필터 | 막는 문제 (실측) |
|---|---|
| Threshold + 클래스별 1개 선택 | 유령/중복 검출이 Ghost 를 엉뚱한 곳으로 이동 |
| EMA 필터 + 데드밴드 8mm | 목표가 프레임마다 mm 단위로 흔들려 접근이 수렴 안 됨 |
| 조작 중 동결 + 파지 시 강체 부착 | 접근/운반 중 목표가 튀면 파지 실패, 낙하 |
| 작업공간 게이트 | 가림/배경 깊이로 만들어진 비정상 3D 값 (Qwen 은 회당 최대 45회 기각) |
| 탑 보호 | 완성 탑 근처 오검출로 탑을 다시 허무는 동작 |

E2E 80회 실측에서 실패 13회는 전부 정체 후 타임아웃이고, 완성된 탑이 무너진
사례는 없음. 오검출이 Belief 까지 도달하지 않았다는 의미.




## Decider Network — 행동 선택

Cortex 의 의사결정은 매 스텝 결정 트리를 내려가며 현재 할 일을 고름:

```
빨→노→연→파 순서로 다음 블록 선택 → 접근 → 파지 → 들어올림 → 운반 → 적재 → (반복)
```

이 로직 자체는 스톡 그대로 사용 (수정한 것: 쌓기 순서, 적재 위치 파라미터).
대신 행동 계층에서 세 가지를 해결함. 제어기(RMPFlow)는 고치지 않고 목표를 바꾸는
방식:

- **carry-high 운반**: 낮게 운반하면 탑 회피력과 목표 인력이 상쇄되어 탑 앞에서
  정체함. 운반 경로를 높여서 해결
- **최소 회전 파지**: 큐브는 90° 대칭이라 등가 파지 자세가 4개. ②의 yaw 로 손목
  회전이 최소인 자세를 선택. 손목이 관절 한계까지 감기는 문제 제거
- **정체 감시자**: EE 가 4초간 5mm 미만 이동이면 장애물 임시 해제(2초) + 자세 섭동으로 탈출
